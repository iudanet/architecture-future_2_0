Текущее корпоративное DWH. Нет поддержки вендора и обновлений безопасности, в нём реализована бизнес-логика направлений. Новых задач не берём; данные переносятся в Lakehouse через CDC, затем режим read-only и вывод (Retire). Сценарии: S1, S5.
